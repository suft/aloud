# Security policy

## Supported versions

Only the latest release gets security fixes.

## Reporting a vulnerability

Use GitHub's private vulnerability reporting:
<https://github.com/suft/aloud/security/advisories/new>.
Please don't open a public issue for a vulnerability.

We acknowledge a report within 7 days.

## In scope

- EPUB parsing (ZIP, XML and HTML)
- Model and update downloads
- The Tauri IPC surface (the commands the app window can call)
- The release pipeline
